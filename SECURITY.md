# Security policy

## Supported version

Security fixes are applied to the latest commit on `main`. Vera does not currently maintain parallel release branches.

## Report a vulnerability

Use [GitHub Security Advisories](https://github.com/Afnanksalal/vera/security/advisories/new) for private disclosure. Do not open a public issue containing exploit details, credentials, account data, payment evidence, or personal information.

Include the affected version or hosted URL, impact, reproduction steps, and a minimal proof of concept. Do not access another user's data, move real funds, degrade service availability, or retain data encountered during testing.

There is currently no paid bug-bounty program. The public security architecture and deployment boundaries are documented at [vera.18.61.174.6.sslip.io/security](https://vera.18.61.174.6.sslip.io/security) and in [docs/SECURITY.md](docs/SECURITY.md).
